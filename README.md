# Dental PMS

Offline-first patient records, appointments and prescriptions for a practising dental clinic. Built with Electron, React 19 and SQLite, with a Gujarati UI.

## Run it

Requires Node.js 22.

```bash
npm install
npm run dev
```

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the app in development mode |
| `npm run build` | Build the app |
| `npm run dist` | Package the app for distribution |
| `npm run typecheck` | Run the TypeScript type checker |
